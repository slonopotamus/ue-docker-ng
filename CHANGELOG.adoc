= ue-docker-ng
:slug: slonopotamus/ue-docker-ng

This document provides a high-level view of the changes to ue-docker-ng by release.
For a detailed view of what has changed, refer to the {uri-project}/commits/main[commit history] on GitHub.

== 1.2.5 (2026-08-26)

* *Breaking change* Images are no longer pushed to remote registry by default.
Use `docker buildx bake --push` if you want to push images.

== 1.2.4 (2026-08-11)

* Build Unreal Engine 5.8.1 by default
* Use all cores when building Unreal Engine

== 1.2.3 (2026-07-28)

* Fix files ownership in Linux minimal image

== 1.2.2 (2026-07-26)

* Workaround windows-source-prep image build failure

== 1.2.1 (2026-07-26)

* Fix windows-base and linux-base image targets

== 1.2.0 (2026-07-26)

* Remove default target
* Improve engine changelist auto-detection
* Always use latest Visual Studio channel.
It is impossible to determine which VS version UE wants from `Windows_SDK.json`.

== 1.1.0 (2026-07-17)

* Enable caching of GitDependencies files
* Switch Linux image base to Ubuntu 26.04
* Remove `gpg-agent`, `python3-dev`, `python3-pip`, `software-properties-common` from Linux image
* Change `ue` UID from 1000 to 1001 to prevent conflict with `ubuntu` user
* Change default tag namespace to `slonopotamus/ue-docker-ng`

== 1.0.0 (2026-07-12)

Initial release.
